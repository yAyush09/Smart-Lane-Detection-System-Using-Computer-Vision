# SmartLane – AI-Powered Lane Detection System

## Overview
SmartLane is an AI-powered lane detection project designed to identify road lane markings for autonomous driving applications using Computer Vision and Deep Learning.

The project explores two approaches:
1. **Traditional Computer Vision:** Uses Canny Edge Detection, Region of Interest (ROI) masking, and Hough Transform to detect lane lines.
2. **Deep Learning:** Uses a U-Net-based CNN model for lane segmentation.

## Features
- Lane detection using image processing techniques.
- Lane segmentation using a deep learning model.
- Canny Edge Detection and Hough Transform.
- Region of Interest (ROI) masking.
- Image and video-based lane detection.
